# Sparse L2 surface observation adapter — HOST candidate, native not_run

The P2 adapter was developed against immutable dev18 and is now integrated with
the frozen dev19 P1 parameter-review changes in a new combined candidate. It is
not installed, not loaded in Blender, not visually qualified, and contains no
new constructor, fitting, normal repair or production material.

## Existing CLI, explicit new option

`hardsurface observe` accepts optional `params.sparse_evaluation`:

- `mode`: `source_bound_sparse_observation_v1`
- `object_id`: one exact authenticated source UUID
- `expected_source_modifier`: the complete actual noncosmetic saved modifier
- `level`: integer 2

It requires `normal_policy=geometry_normals_v1`, `wire.enabled=false`, one exact
`visible_object_ids` selection in every evaluated view and no explosion. The
saved source must be enabled L0/L0, quality 6, with limit-surface and creases and
no custom normals. Other settings are matched exactly, not defaulted from an
unrelated source. Old requests do not acquire the new option or fingerprint.

Source authentication reuses sparse diagnosis: registry-bound actual authorship,
FACE parent slots, semantic labels, complete modifiers and actual control loops.
Scene simplify is refused. The original object is never raised to L2. An owned
separate scene and independent mesh/object copy receive only the reported L2
modifier delta. The existing observer then freezes actual evaluated geometry and
attests native corner normals, sharp/smooth state and material at render bounds.
The original source, metadata, modifier, registry, geometry, normal state and
scene settings are checked before cloning, at each render bound, after rendering
and after owned-clone cleanup. No .blend is saved. External host guards and
whole-job watchdogs remain required. HOST tests do not prove Blender cleanup or
render behavior; the first native probe must establish those properties.

Both `neutral` and `reflection_strips` are temporary diagnostic materials, not
production materials. They author no asset textures and grant no material or
surface qualification. Reflection strip direction changes do not change camera.

## Source-bound surface fields

Surface acquisition is standalone P2 work. The combined P1 edit-review schema
and runtime explicitly reject surface_export; it remains nonrendering with its
original six-process bound and has no implicit observation stages.

`hardsurface subdivision diagnose` retains sparse L0/L1/L2/L3, explicit geometry,
and rendering disabled. Optional `surface_export` uses the existing fields plus
`binding_mode=source_bound_sparse_observation_v1`, still with two CPU threads.
The source remains L0; the pinned successful sparse observation contains the
exact original L0 and effective L2 profiles. Old observation binding remains
unchanged and cannot consume the new report through the legacy profile.

Bind one or two exact observation images and their report by SHA and bytes.
Declared projection inputs must exactly match new native render-time values.
L2 native position/topology and corner-normal identities must equal the rendered
L2, and source semantic identity must equal the independently authenticated
source. L3 is a diagnostic sample, not an L2 image. Full native loops, polygons,
triangles, normal vectors, sharp/smooth/crease state and actual FACE ancestry
remain required. No normalization, repair, proximity inference or index-order
substitution is allowed. Existing output and resource limits remain in force.

Outputs remain the whole diagnosis report, ordinary L0–L3 geometry, source maps,
projection calibration and L2/L3 native surface JSON. Only whole-job success,
final preservation and matching descriptors make the export usable. Partial
files remain diagnostic evidence. Visual and user acceptance remain not_run.

## Bounded native qualification protocol

A native qualification request must bind an existing caller-approved source by
exact SHA, object and modifier identities. Plan neutral observations, orthogonal
reflection-strip observations and nonrendering surface exports as separately
bounded work units. Fix camera coordinates and framing from geometry and
worst-point evidence before reviewing results. Compare paired observations with
the same camera and framing; retain the worst view.

Declare CPU, time, sampled process-tree memory, image dimensions and byte limits
in the request. Sampled resource budgets are not OS hard isolation or a speed
promise. Stop on identity, preservation, resource or execution failure. Further
sources and repeat executions require their own exact scope and evidence.
Technical completion does not establish visual acceptance or production quality.
