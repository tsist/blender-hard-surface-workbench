# Low-density hard-surface development plan

Updated 2026-10-08. Development candidate: `reflection-anchor-diagnostic-dev.21-r1`, protocol `0.2.0`.

## Current scope

The workbench develops plugin-owned domain operations and CLI-orchestrated complete work units for a bounded low-density, quad-oriented subdivision workflow. The current validated evidence is concentrated in a single-hole rounded plate. Further optimization of that practice object is paused; the next development decision is to select a higher-level modeling object from accumulated knowledge cases. Source-cage integrity, edit provenance, evaluated geometry, actual observation coverage, recovery, and intended-use qualification are separate gates.

This is a development roadmap, not a production certification or a claim of general commercial modeling capability. A repository push does not install the plugin, validate a new native operation, or qualify an asset for delivery.

## Acceptance model

- Source and editing: complete topology, connectivity, loops, edit locality, controlled face growth, and protected originals.
- Evaluation: fixed subdivision settings and identity-linked source/evaluated geometry. Finite sampled surface differences describe that comparison; they are not nominal dimensional errors or a guarantee over a continuous surface.
- Visual review: identity-matched unoverlaid views, actual surface normals where relevant, adequate multi-direction reflection coverage, and worst-region inspection. A passed job or matching hash cannot replace sufficient observation.
- Delivery: save/reopen, dependency recovery, frozen holdouts, documented limitations, and intended-use acceptance.

Maintain separate technical pass, geometry failure, insufficient-observation, not-run, and qualification states. Historical failures remain historical failures even when a useful output was preserved. Do not relabel an earlier failed outer batch as successful because a later review recovered one result.

## Longer roadmap

Candidate directions include adjacent holes and slots, thin-wall boxes and lids, stepped revolved parts, round-to-square transitions, curved-surface openings, and modular assemblies. These are a capability map, not a mandatory curriculum order or a preselected next object. Select the next practice object from the accumulated cases, then introduce a bounded number of new variables. Add unseen combination holdouts only after implementation is frozen; a case used for tuning becomes regression evidence and needs a replacement holdout.

The film/product route requires editable source geometry, evaluated high-resolution results, and shot-appropriate shape and surface review. The game route separately requires controlled low-poly derivation, UVs, fixed triangulation, bake/cage and normal-tangent conventions, exchange reopen, LOD, and target-engine checks where applicable. These routes are not yet complete.

Arbitrary mesh repair, manufacturing-grade accuracy, unrestricted parameter combinations, universal asset coverage, and broad commercial qualification are not current claims.
