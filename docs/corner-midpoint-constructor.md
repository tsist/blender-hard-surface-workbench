# Explicit midpoint corner-column constructor

The optional `sparse_cage.corner_columns` accepts exactly
`{"schema":"corner-columns-midpoint/1.0"}`. It requires the explicit
`sparse_control_cage` route, a supported fixed frame, `axis_plane_v1`, and four
roundover bands. Absence preserves previous saved declarations and behavior.

Construction builds the original closed body, inserts two disjoint complete
corner columns at semantic parent-edge midpoints, freezes a new axis reference,
then applies zero to two user cuts. Structural columns are baseline topology,
not user insertions. IDs derive from version, route and semantic parent addresses,
never coordinates or an entire source hash. Hole edits cannot rename the exterior.

Each structural baseline cycle contains 44 edges. Actual closed continuation,
winding, hole exclusion and ancestry are verified. The new outer interface
starts at 36 points and gains two per user cut. Crossing cuts expand structural
cycles through their real split-edge maps. Reference 1.1 binds actual baseline
cardinalities and structural loops; legacy reference 1.0 stays unchanged.

Midpoint placement preserves old control coordinates and their polygon surface.
It does not preserve or qualify the subdivision limit. No optimizer or fitting
coefficients are admitted. Use the existing bundled `hardsurface-cli` complete
`hardsurface run` unit and deterministic saved-edit reconstruction. Enabling this
topology is not an implicit migration of an old saved body.

Check the complete source in authored and float32 metre coordinates, including
flat transitions, extraordinary vertices and both diagonal intersection tests.
Record omissions in regular-patch predictions; they cannot qualify omitted
regions. The source-bound native diagnostic exports all evaluated faces and
authenticated parents, but new sources still require fresh native evidence.

Keep the caller's shape priorities and reference metrics separate from strict
mesh validity, identity and edit protection. A structure-first assessment may
retain dimensional deviation as a reference reading. Never rewrite historical
criteria/results, hide missing measurements, weaken technical gates or equate
execution with shape acceptance. Sparse `quality.stage: full` remains unavailable.
