# Source-bound subdivision and semantic bore measurement repair

Candidate: structural-native-dev.6. New independent source copy; no Blender execution of this version is authorized or claimed by this document.

## Why the parent batch stopped

The dev.5 parent passed 27 real native identity/fault cases, each with an independent saved-file reader (54 Blender processes). Its first complete CLI build also passed actual structure, intermediate checkpoint reopen and final reopen (4 processes). The next read-only subdivision diagnosis completed but failed required L3 acceptance, so all remaining work stopped. PQ geometry and observation jobs were not started.

Two different issues must remain separate:

1. The source constructor and historical reference measurements used quality=6 and use_limit_surface=true. The diagnostic fixture omitted settings, taking quality=3 and use_limit_surface=false. That diagnosis did not measure the same evaluation profile.
2. The existing bore selector classified faces from an absolute Z spread above 0.000001 mm and a radius-near condition. A host-only annular fixture proves that a 0.0000011 mm perturbation of a neighboring cap support band can add its points to the rim sample while the bore itself remains unchanged. This is a classifier vulnerability, not proof that every reported native failure is a false positive. The actual failed diagnosis did not export its evaluated mesh, so exact native membership causality still needs new authorized evidence.

The parent L2 finite-surface check passed at 0.0334243644 mm. L3 finite proximity also passed at 0.0351936406 mm, but the bore feature witness failed after reporting 489 top-rim points and a radius as large as 9.3489813789 mm against the neutral 8.5 mm nominal. The failure remains failed; no threshold or geometry was changed to rename it a pass. These are neutral numerical fixture values, not approved project design parameters.

## Intended bounded repair

- Explicitly separate an unqualified legacy diagnostic evaluation profile from source-bound qualification
- For source-bound checks, bind expected and actual original modifier settings and report every intentional diagnostic-level change; refuse unsupported geometry-affecting settings
- Validate the real original authored identity and separately held saved-source registry
- Carry actual native FACE INT provenance and unique face slots to each evaluated level; verify complete descendants and matching semantic labels
- Select the bore wall from that validated semantic face domain. Build its rim boundaries from actual subset connectivity, rather than a Z-spread or near-radius membership heuristic
- Keep finite surface, dimensional, hole-error, volume sanity and topology checks, with their unchanged declared tolerances
- Apply the semantic measurement path to both read-only diagnosis and the authored production bridge; do not let a legacy result acquire source-bound qualification by aggregation

This does not add the separately outstanding arbitrary-direction section rays, frozen flat-mask measurement, perspective lens interface, silhouette comparator or holdout qualification. Native and visual acceptance remain pending.
